# ROS 2 Systems Engineering Notes

[English](README.md) | [中文](README.zh-CN.md)

An engineering handbook covering ROS 2 fundamentals, communication, TF2, simulation, Nav2, MoveIt 2, DDS, performance, embedded deployment, fault tolerance, cloud robotics, and current robotics tooling.

## Contents

- ROS 2 workspaces, nodes, topics, services, actions, parameters, and lifecycle
- DDS/QoS, TF2, URDF/Xacro, Gazebo, Nav2, MoveIt 2, and embedded deployment
- Performance profiling, fault tolerance, security, cloud robotics, and frontier tooling

The full PDF is [ROS2开发工程师_系统学习笔记.pdf](./ROS2开发工程师_系统学习笔记.pdf), and the chapter map is [完整目录.md](./完整目录.md). The Chinese companion is [README.zh-CN.md](README.zh-CN.md).

This is a structured learning and reference artifact, not a claim of production support for every listed subsystem.
