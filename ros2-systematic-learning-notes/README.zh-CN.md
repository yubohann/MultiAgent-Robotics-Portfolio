# ROS2 机器人开发工程师系统学习手册

[English](README.md) | [中文](README.zh-CN.md)

**面向 ROS2 开发工程师岗位的系统学习手册，覆盖从基础到前沿的完整知识面。**

内容系统整理 ROS 基础，通信机制，TF2，建模仿真，Nav2，MoveIt2，DDS，性能优化，嵌入式部署，安全容错，云机器人与前沿技术等核心内容，持续更新。

## 章节总览，18 章

1. **ROS 基础与环境搭建**，覆盖工作空间，命令行工具，通信机制与 ROS2 新特性
2. **ROS 工作空间与功能包管理**，覆盖 catkin 与 colcon，依赖管理，版本控制与构建系统
3. **话题通信机制**，覆盖发布订阅，消息类型，调试工具与性能优化
4. **服务通信机制**，覆盖服务模型，C++ 与 Python 实现，分布式优化与安全
5. **Action 通信机制**，覆盖 Goal，Feedback，Result，长任务，取消与错误处理
6. **ROS 工具与调试**，覆盖参数服务器，rqt，rosbag，launch 与生命周期节点
7. **机器人建模与仿真**，覆盖 URDF 与 Xacro，Gazebo，传感器建模与联合仿真
8. **TF 与 TF2 坐标变换**，覆盖变换树，发布订阅，时间旅行与多机器人集成
9. **传感器集成与数据处理**，覆盖 LiDAR，IMU，相机，时间同步与高性能驱动
10. **导航与路径规划**，覆盖 Nav2，AMCL，代价地图，多机器人协同与 AI 集成
11. **MoveIt2 运动规划**，覆盖运动学，OMPL，轨迹执行，实时重规划与插件开发
12. **ROS2 DDS 通信机制**，覆盖 DDS 原理，QoS，实时性，安全部署与 Zenoh
13. **ROS 与 Docker 容器化部署**，覆盖镜像构建，编排，K8s 与 DevOps 前沿
14. **多机器人系统协同**，覆盖任务分配，时间同步，协同 SLAM 与容错安全
15. **ROS1 与 ROS2 对比迁移指南**，覆盖架构，API，构建系统与 ros1_bridge
16. **ROS 性能分析与优化**，覆盖通信性能，Executor，零拷贝，实时内核与追踪
17. **ROS 与机器视觉**，覆盖 OpenCV，深度学习集成，模型部署与视觉 AI 前沿
18. **ROS2 嵌入式与边缘计算**，覆盖交叉编译，Jetson，资源优化与系统裁剪

每章均含 2024 至 2026 最新技术前沿，包括 LLM 导航，VLA 与 VLM，3DGS，扩散策略，基础世界模型等，覆盖从就业岗位真题到前沿研究的完整知识面。

*Bohan Yu，ROS2 系统学习笔记。*
