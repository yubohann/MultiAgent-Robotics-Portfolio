# Bohan Yu | 多智能体机器人作品集

这是一个面向具身智能、多智能体系统和机器人研究工程的项目合集，覆盖可复现实验合同、仿真与回放、ROS 2 自主系统、评测基础设施和课程工程。

英文版 [README.md](README.md) 是 GitHub 默认展示入口；本文件提供中文导航。

## 研究项目

- [Rivermark Benchmark](rivermark/README.zh-CN.md)：多传感器 Search3D 基准基础设施。
- [RoboCup CBG-WM](robocup-cbg-wm/README.zh-CN.md)：规则约束的多机器人视觉导航与回放。
- [Robocon MID-360 Autonomy Stack](robocon-mid360-autonomy-stack/README.zh-CN.md)：Livox、FAST-LIO2 和 ROS 2 竞赛自主栈。
- [AeroCityBench](aerocity-bench/README.zh-CN.md)：城市拓扑与目标过程变化下的 3D 多无人机搜索基准。
- [HM3D Realised-QD](hm3d-realised-qd/README.zh-CN.md)：基于真实执行回执的 HM3D 多无人机协作探索与 QD/RL。
- [AeroGate Graph](aerogate-graph/README.zh-CN.md)：图规划、编队控制和动态闸门仿真。
- [FraudGraph ML Engineering](fraudgraph-ml-engineering/README.zh-CN.md)：图与序列联合欺诈检测工程。

完整路径、检查命令和证据边界见 [Portfolio Guide](docs/PORTFOLIO_GUIDE.zh-CN.md)。
