# Media Notes

This directory holds the compact replay media and generated previews for the RoboCup CBG-WM project.

- `large_scale_50v50_isaaclab_preview.gif` is the 12-second GitHub replay preview with heading noses, bases, zones and a telemetry panel.
- `large_scale_50v50_isaaclab_replay.mp4` and `large_scale_50v50_replay.mp4` are the recorded replay exports.
- `最终回放_三视角同步拼接版.gif` is the synchronized three-view replay of the audited two-robot match, with top view and both first-person views.

The three-view GIF keeps a 720 pixel width at 12 frames per second so the compact checkout stays light for GitHub display.

These files are presentation artifacts. The replay record, source traces and scoring summaries live under [`../reproducibility.md`](../reproducibility.md) and [`../rl_data/`](../rl_data/).
