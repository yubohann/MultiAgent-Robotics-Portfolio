# Media Notes

This directory contains compact replay media and generated previews for the RoboCup CBG-WM project.

- `large_scale_50v50_isaaclab_preview.gif` is the short GitHub-friendly replay preview.
- `large_scale_50v50_isaaclab_replay.mp4` and `large_scale_50v50_replay.mp4` are the recorded replay exports.
- `最终回放_三视角同步拼接版.gif` is the synchronized three-view replay.

The media files are presentation artifacts. The reproducibility record, source traces, and evaluation summaries are documented under [`../reproducibility.md`](../reproducibility.md) and [`../rl_data/`](../rl_data/).
