# 外部方法输入语义矩阵（2026-08-03）

## 结论

截至本次审查，**没有一个候选可以作为 G2-I 的实质外部三维方法关闭 C 门**。这不是因为缺少可运行代码，而是因为候选方法所定义的输入和本基准公开的信息不等价。强行把私有网格、渲染深度、完整地图或上游专用能耗地形矩阵提供给方法，会改变信息权限；反过来改写上游算法阈值、输入构造或核心模块，也不能再称作锁定上游方法。

机器可读来源是 `external/candidate-input-semantics.json`，每次推进 C 门前必须运行：

```powershell
.\.venv\Scripts\python.exe tools\audit_external_candidate_semantics.py
```

该审计当前应稳定输出 `BLOCKED_NO_SUBSTANTIVE_EXTERNAL_G2_I_METHOD`。这表示门禁诚实阻止，而不是实验失败；它禁止把可运行的求解器、二维迁移诊断或低层路径组件误写成外部三维搜索基线。

## 方法与结论

| 候选 | 上游真正需要的输入 | 与 G2-I 的关系 | 当前处置 |
| --- | --- | --- | --- |
| OR-Tools | 任务节点、成本图、车辆起点、预算 | 公共检查单元和安全转场图可以直接表达为路由实例 | 已完成独立进程三城 L0 及三城完整四机 CF2X L1 开发闭环；只是外部求解器，不是外部三维搜索方法，不能关闭 C 门 |
| FUEL | 深度/点云射线、细粒度自由空间与前沿 | G2-I 不公开这些传感器语义；私有网格或渲染深度不可补给 | 仅保留未来 G1-U 探索候选，禁止接入 G2-I |
| FALCON | 覆盖图/点云或地图表示及其轨迹环境 | 尚未证明 atlas 到上游地图语义等价；许可证也未闭合 | 排除，等待上游许可证和无损输入映射 |
| RACER | 在线点云/占用图、前沿/视点生成、ROS 通信 | 前沿探索不是预定义公共检查单元的调度 | 排除，且许可证边界未闭合 |
| MARVEL | 二维栅格和二维有限视场 | 可做二维迁移诊断，丢失三维朝向和检查约束 | 仅附录，不能加入 G2-I 主榜 |
| mav_voxblox_planning | TSDF、ESDF 与已给定目标 | 是低层轨迹规划，不选择检查区域 | 不能计作独立搜索方法 |
| EA-A*-HWGA | 风机任务点、山地地形、专用能耗矩阵和动态基地 | 用 atlas 代替这些输入会重写方法；上游仍是投稿中稿件 | 只作为检索线索，当前不接入 |
| HighStar | 在线 OctoMap、未知空间前沿、视点和轨迹凸包 | 其核心是从射线建图产生前沿；G2-I 不公开该传感器流 | 仅可在独立 G1-U 传感器档重审 |
| EPIC | 在线 LiDAR 点云、未探索空间与拓扑图 | 提供私有网格/渲染 LiDAR 会越权；以 atlas 重写其建图核心也不可接受 | 仅可在独立 G1-U LiDAR 档重审 |
| TU Darmstadt 3D Coverage Path Planning | 完整/目标网格、地面机器人网格导航与重建 | 它是已知完整网格上的地面检查，而非 CF2X 的公开 atlas 搜索 | 仅作为相关工作，不作为可运行基线 |

## 审查依据

- 2026-08-03 的 v8 公共净空适配器已在三个 calibration ancestor 完成完整 300 s、四机 CF2X/PhysX
  回放：均全员返航、零碰撞、零越界、零 deadline miss，并经 public/private receipt binding 独立校验。
  该适配器发现同一区域低空线段会穿越**公开**建筑包络时强制使用公开 safe-sky；A01 因而保留安全但零
  确认的真实结果。公开摘要见
  `reason/benchmark-external-methodology-audit-20260802/current-boundary-l1-gimbal-v1-20260803/external-ortools-cf2x-l1-v8-public-summary.md`。
  它验证外部运行时的物理执行链，不改变 OR-Tools 的方法类别。
- FALCON 是三维覆盖探索，而非隐藏目标搜索：论文 DOI `10.1109/TRO.2024.3522148`，官方仓库为 `HKUST-Aerial-Robotics/FALCON`。
- FUEL 的锁定来源、容器构建和否定烟雾已经留存于 [外部三维候选审查](../reason/benchmark-external-methodology-audit-20260802/external-3d-candidate-screen-20260803.md)。它在公开风格 ROS 图中没有生成路线，根因是细粒度射线建图语义缺失，而不是一个应通过调参掩盖的偶发现象。
- MARVEL 是二维有限视场探索：DOI `10.1109/ICRA55743.2025.11127700`，不得被改写为三维目标搜索结果。
- EA-A*-HWGA 的官方仓库在 2026-08-03 固定于 `f5817e92e36b3ec9a2a81a23ecad109c191ba2b6`，MIT 许可证；README 明确其论文是“投稿中”，所以不能作为已发表基线来表述。
- HighStar 的官方仓库在 2026-08-03 固定于 `6dd50cbc003a33c736d64a04f2950e6fa5001280`；其论文是 2025 年在线三维探索，但锁定树没有根 SPDX 许可证，且其输入是 OctoMap 前沿，不是 G2-I atlas。
- EPIC 的官方仓库在 2026-08-03 固定于 `d73c3150e57d669ac21bcad5c859f52c2827c9ba`，GPL-3.0；2025 年 RA-L 论文明确以 LiDAR 点云进行探索，故不能以私有几何补齐其输入。
- TU Darmstadt 的项目在 2026-08-03 固定于 `b2d035af8e0800d819b62c50d3c1a8936503f72d`，MIT；其 IEEE SSRR 2022 论文 DOI 为 `10.1109/SSRR56537.2022.10018726`，README 明确要求完整/目标网格和地面机器人网格导航。

## 后续准入规则

新候选只有同时满足下列条件才可以把 `c_gate_eligible` 改为真：

1. 锁定上游地址、完整提交、许可证及独立运行环境；
2. 上游所需的每一种输入都能由 G2-I 已公开字段直接表达，且不注入私有真值、私有几何或测试划分信息；
3. 适配器不改写上游搜索/检查核心；任何必要的格式转换都有可逆、字段级说明；
4. 完成只读 ABI 烟雾、三座 calibration 城的 L0 与同边界四机 CF2X L1 回放；
5. 所有超时、崩溃、碰撞、越界和适配器故障计入失败分母。

在此之前，正式状态维持 `PILOT ONLY / FORMAL NO-GO`。更合理的短期工作是继续积累内部、目标无关的公开检查基线和发布复现证据，而不是把不兼容的探索系统改造成 G2-I。
