## 1. 任务结论先冻结

### 1.1 两条轨道，不混榜

- `G1-U / exploration-3d`：粗先验、局部 occupancy、自由空间探索。用于 FALCON/frontier/sweep 类方法的 target-free 诊断。
- `G2-I / geometry-search-3d`：公开、目标无关的 inspection atlas 和 mission sector，私有目标只决定 OBSERVE 是否产生匿名确认回执。它是唯一候选主榜。
- `perception-search-3d`：RGB/RGB-D 目标检测，延后到独立版本；geometry 主榜不强制 RGB。

### 1.2 G2-I 的固定生成顺序

```text
CitySpec + execution contract
  -> target-independent atlas
  -> public starts and return budget
  -> public mission sector (hash frozen)
  -> private target/distractor sampling inside sector
  -> public episode projection
  -> public method -> unified controller -> OBSERVE
  -> evaluator-private receipt -> metrics
```

禁止根据自有方法结果改变 atlas、sector、目标数、确认距离、预算、难度分层、停止条件或排除规则。所有正式参数必须在自有方法长训练前冻结。

### 1.3 当前已知反证

- 旧的全 atlas exhaustive route 在 300 s 内工作量超预算，不能作为 canonical baseline。
- 2026-08-01 的 five-ancestor L0 bracket 已证明非 oracle 存在非零搜索信号，但 oracle 有一个 ancestor 未全员返航；因此只能叫 calibration。
- coarse/full prior 的结果差异很大，coarse planner 的碰撞不能解释为“粗先验天然不可用”，它目前只是安全性不足的诊断实现。
- sector split probe 样本不足，不能把 `INSUFFICIENT_DATA` 当作通过。
