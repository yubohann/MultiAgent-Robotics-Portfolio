# 高保真长任务成本控制研究

日期：2026-07-31
状态：`EVIDENCE-BACKED DESIGN INPUT / NOT A PERFORMANCE CLAIM`

## 1. 结论

高保真平台降低长任务成本的共同做法不是把正式任务时钟任意缩短，也不是用低保真成绩替代正式成绩。它们把成本拆到不同层：批量、headless 的训练采样；低频的高层决策；预编译的静态几何；按需的传感器渲染；以及只对少量候选运行昂贵评估。

对 AeroCityBench 的不可变约束是：`300 s` 仍是未来正式 G2-I episode 的**模拟执行时钟**。host timeout 只是卡死保护。CF2X/PhysX、碰撞、OBSERVE、确认和返航语义不能因节约成本而在 L1 改弱；L0 不得产生正式分数。

当前 G1-U 没有公共检查图，因此无法把连续表面扫描压缩为有科学意义的候选集合。正确的降成本前置条件是 G2-I：先公开目标无关的有限检查区域/单元和安全转场图，再让方法决定检查顺序、责任分配和冗余，而不是让方法猜私有 target witness。

## 3. AeroCityBench 的成本合同

### 3.1 五层执行

| 层 | 允许做什么 | 不允许做什么 |
| --- | --- | --- |
| 静态编译 | 从CitySpec预编译G2-I atlas、检查单元、区域邻接/安全转场图、公开代价界；以版本/hash缓存只读结构。 | 引入目标、target process、support ID、witness、ray结果或任何私有派生字段。 |
| L0机制训练 | headless、向量化、课程城市、2机短任务、无RGB，筛选控制逻辑和责任选择。 | 生成正式成绩、查看formal test、以L0分数替代L1。 |
| L0公开可搜索性校准 | 在隔离calibration运行oracle、surface-inspector、G1-U frontier、atlas-aware planner/auction，冻结非零且未饱和的难度括号。 | 根据自有QD+RL结果移动目标、任务时钟或确认语义。 |
| L1正式复核 | 对经L0筛选的少数方法、seed、checkpoint运行CF2X/PhysX、完整300s时钟和完整回执。 | 缩短时钟、降低控制/碰撞语义、删除超时/崩溃/失败episode。 |
| L2视觉 | 在OBSERVE事件触发RGB-D/segmentation，或用于分层视觉审查和视频。 | 把视觉审查吞吐当作L1吞吐，或混入无RGB的G2-I排名。 |

### 3.2 高层候选化，而非缩短任务

G2-I不将私有目标离散化给方法。它把目标无关的结构检查义务离散化为有限公共单元。单元尺度由确认range、FoV、dwell、允许视角误差、机体净空和安全站距联合推导；每个单元应记录其公开边界和atlas版本。

高层方法在固定决策周期只选择以下内容：下一个检查单元/区域、heading/OBSERVE意图、队伍责任、冗余和公开消息。共享CF2X controller继续在固定小物理步推进。这样减少的是planner候选和渲染次数，不是飞行物理或成功语义。

### 3.3 连续门与停止条件

1. 先验证atlas不泄露目标，且配对target-process使用相同atlas。
2. 再验证surface-inspector能在中等calibration城市中以公开信息产生稳定、非零、未饱和确认；private oracle只证明可解性。
3. 通过后才训练MAPPO；QD+RL仍先在独立方法工作区做低成本机制门，再作为冻结G2-I的外部验证。
4. 每个候选在L0中以预注册规则筛选；对被淘汰方法随机回查L1，估计successive-halving误杀，而非假定L0排序永远正确。
5. 正式前以同一城市、同一机群、同一控制频率、GPU/driver/容器测量PhysX-only、ContactSensor、depth、OBSERVE RGB-D和RGB-D+instance五档RTF、显存、deadline miss与渲染次数。

若非oracle方法仍然全零，或atlas字段能够预测目标/过程/split，则停止L1大矩阵和所有QD+RL长训练；这说明任务接口还没有定义出公平的公开搜索对象，而不是增加GPU时间能解决的问题。

## 4. 可执行的最小成本路径

1. 实现并审计atlas compiler与surface-inspector。
2. 在3--6个隔离calibration城市做L0 bracket，只改变公开任务单元数量与城市复杂度，不改变私有真值规则。
3. 选择少数方法/seed进入四机L1，先测完整episode闭环和每档传感器吞吐。
4. 根据ancestor级方差和实测RTF计算正式样本量；未通过功效/成本门时降级或停止，不以扩大训练掩盖问题。

这一路径先消除当前的定义缺陷，之后才减少实验量；它不会承诺某个预先估计的wall-clock总时长。
