# Legacy release configurations

`v0.1.json` is retained only to preserve the history of the superseded construction plan. It uses release schema v1, oversized 100/160/224/288 m assumptions, and obsolete split and target contracts. The v2 loader accepts only schema v2 configurations.

Use `smoke.json` for software checks and `v0.2-pilot.json` for bounded research pilots. Both remain development configurations, and the frozen paper release comes later.
