## 为什么写这个

市面上的机器人教程大多是知识点散装：讲 ROS 的不管调试，讲算法的不管装车。这本笔记回答一个具体问题。

**一个零基础的新队员，怎么在一年内成长为能独立装机，能调车，赛场上能解决问题的人？**

我把两年里真实的经历整理成八篇三十七章：选型，调试，案例，深入，内功，背景，传承。每一章从一段亲历的场景起笔，落到可执行的清单。精选的问题都写成案例卡，现象，排查路径，根因，解决，预防。

## 适合谁读

- ROBOCON 及其他机器人竞赛队伍的新队员，机械，电控，视觉，集成方向均可
- 负责系统集成，上位机，雷达与感知方向的同学
- 对机器人系统工程感兴趣，想少走弯路的同学
