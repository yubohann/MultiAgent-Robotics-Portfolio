# 第 15 章 赛场事故案例

> 最重的几次教训都来自现场，方案能在实验室里慢慢打磨，故障只在赛场上出现。这一章四张卡，全部来自现场实战。

## 案例 1：高温备馆抢修，从傍晚修到后半夜

**现象**：七月六日首批进场，备馆高温无空调，风扇吹的都是热风。练习赛碰撞频发，一天下来零件损坏几处，最严重的一次烧了舵机。白天打练习赛，晚上修车，全队从傍晚修到后半夜，工作台摆满了拆下来的件。

**排查路径**：

1. 损坏评估，清点伤情，把坏件与嫌疑件分开列清单。嫌疑件不轻易算进损失，等复测结果再定
2. 按备份件清单换件，能换最小单元的就换最小单元，减少二次拆装带来的新偏差
3. 机械复核，换完件先过装配关系，螺丝，间隙，同轴度。公差按图纸逐项过，不靠手感
4. 我负责定位链恢复，两段式外参里只重标受影响的那一段，恢复范围依据机械改动清单来定，没动过的段保持原值
5. 跨接口联调，串口，CAN，无线各过一遍，同条件复测后交回比赛。复测条件与比赛工况一致

**根因**：舵机是在冲击载荷叠加堵转的工况下烧的，保护手段不够，选型余量偏紧。高温让问题暴露得更快，器件温度很高，参数也容易漂移。冲击载荷叠加堵转时，机构被撞后电机顶着障碍继续出力，电流长时间高于额定，线圈温度快速上升，保护缺位时没有任何环节叫停。堵转电流高出额定数倍，热量积累很快，留给人反应的时间窗口很小。换件顺序也有讲究，先换影响行走与安全的件，感知与标定的恢复排在后面，抢修时间有限，优先级事先排好。

**解决**：受损件当晚换完，标定按段处理，同条件复测，原地绕场一圈位姿不发散才放行。舵机对策三条同时执行，加限位，加过流保护，新选型留足余量。第二天的练习赛，车回到场上。当晚的作业按抢修流程走，评估，换件，机械复核，重标，联调，顺序不乱。焊接作业按通行参数执行，烙铁温度控制在 320 到 380 度，焊点 2 到 3 秒完成，先给焊盘挂锡保护。

**预防**：

- 备份件清单按最小可换单元组织，急救包核心件备份一套，耗材两份。急救包由专人负责，用掉的件当天补回，出发前全清单盘点
- 现场抢修五步写进流程，从评估到联调，顺序不乱
- 选型留余量成了全队在电机与舵机上的共识
- 机械改动当天同步到感知与电控，改动清单是标定范围与复测范围的依据

延伸：装配与选型里有两类教训值得单独记。一类是公差，轴承座公差放到半毫米量级，装配时手感与检具都容易放过，跑起来的振动会沿机械链传进感知。另一类是供电，电机再好，供电链路按平均功率配，峰值工况下电压落到器件要求之下，表现就是随机复位与丢数据。两类的规矩一样，验收测到位，装配按图纸公差逐项量，供电按峰值工况逐项测。备馆排期的价值也在这一站反复出现，问题暴露得越早，修复与复测的时间越充裕，后来的习惯是备馆的每一天都按正式比赛过一遍。

## 案例 2：赛前两小时定位抢修

**现象**：正式上场前两小时，定位链路失效，位姿每隔几秒跳一次。前一晚测试还正常，全队高度紧张。操作手站在旁边不敢出声，怕干扰抢修。

**排查路径**：

1. 按六步法先定现象，只记观测，跳变间隔没有规律，先录一段包。现场不做猜测性改动
2. 把链路切成段，二分法一层层切，半段半段地排除。每切一次复测一次，现象跟着哪半段走就锁哪半段
3. 四十分钟后锁定到一块板卡，供电接触不良。轻压供电插头，跳变频率跟着变，判断落地
4. 换上冗余板卡，链路复通，接着做最短回归。回归看位姿连续性与心跳

**根因**：一块板卡的供电接触不良，车一动，接触电阻就变，板卡工作时断时续。插头不紧平时只表现为偶发故障，赛前的设备温度与振动叠加后集中出现。板卡工作时电流一冲，接触点压降忽大忽小，板卡在掉电边缘来回。赛前设备温度高，插头热胀后压紧状态变化，加上运输后的车体振动，三个条件凑齐，故障从偶发变成常态。

**解决**：换上备份板卡，重跑自检链，串口，CAN，无线逐一看通。回归做最短的一条，原地绕场一圈，位姿不发散，心跳正常，合格放行。抢修用掉两小时中的一半，车赶在上场前恢复。回归口径固定成三条，自检全绿，绕场一圈位姿不发散，心跳与链路正常，三条里任何一条不过就继续修。备份板卡平时就按可上台的标准维护，取来就能用。

**预防**：

- 关键板卡常备冗余，装箱的时候就在手边，固定存放位置
- 二分法抢修流程做成卡片，新人照着也切得动
- 每次高速跑动前把接插件按压一遍，成为出发前的固定动作
- 上电自检覆盖每条链路的通断与数据新鲜度，抢修后跑的就是这条链

延伸：间歇性故障的排查要抓住两个变量，时间和动作。记录故障出现的时刻，与操作动作和温度变化对照，规律一出来，范围就能砍掉一半。二分法切的是链路长度，记录对照表切的是时间，两条一起用，抢修才快。

## 案例 3：场地适应期的参数重标定

**现象**：从备馆进正式场馆，同一台机构，同一套参数，投篮落点开始飘。备馆里调好的状态，换了场地就变。该拿的分在丢。

**排查路径**：

1. 先试射，把误差记下来，确认属于系统性偏差。误差方向一致，量大且稳定
2. 按标定表逐距离复测，偏差随距离变化，弹道参数与环境相关。近距几乎看不出，远距明显
3. 查场地，地面状况影响起步与站位，篮筐实际高度与角度和备馆都有出入。几何项的变化与误差分布对上
4. 现场迭代重标，从罚球线到三分线每 0.5 米采一个点，跑了三轮。约十五个点起步，落点误差逐轮收敛

**根因**：备馆与正式场馆的场地条件有差，地面影响走位，篮筐装配角度影响落点，摩擦热还会让初速慢慢漂。参数表在实验室里做好，到现场需要重新标定。弹道参数是经验映射，输入早就不是初始条件本身，摩擦轮的表面状态，球的状态，电压水平，热积累，每一项都在影响出射速度与旋转。地面摩擦改变走位后的实际站位，篮筐装配角度改变入射条件，几何与力学两侧同时有个小偏移，实验室里标好的表到这里就偏了。热的影响是缓变量，复测节奏要跟它对齐。表里的点不是采完就完，每轮重标都要与上一轮的落点记录对一遍，确认是收敛还是震荡，震荡说明还有条件没控住。

**解决**：场地适应期安排专门的重标定窗口，逐距离复测，现场迭代两到三轮，连续射击之后复测热漂。落点误差逐轮收敛，参数版本单独标记，跟着比赛走。每轮结果配上落点误差记录，用了哪些条件写得清楚。重标期间暂停其他并行调试，场地里的变量一个一个改，避免参数与场地同时动。

**预防**：

- 场地适应期第一天留给标定与试射，时间预算写进赛程表
- 标定表按场地存版本，回队归档，下一届知道这里花过多少时间。归档内容带上采样条件，温度，电池状态，连发轮次
- 摩擦热的复测节奏固定，连续射击后必测，热漂复测不合格就回上一版参数
- 试射记录表固定栏目，距离，落点偏差，连发序号，环境备注，四栏一次填全
- 重标完成把新旧参数各留一版，回场打不顺时能换回来

## 案例 4：数据丢失与三重备份的启用

**现象**：一次意外之后，我们才发现关键数据大多只有孤本。标定参数在车上那台电脑里，比赛录像在一块移动硬盘里，文档散在几台机器上。东西没有全丢，但那几天谁都不敢关机，走廊里全是找备份盘的人。

**排查路径**：

1. 盘点损失，把代码，标定表，文档，录像四类逐一理出来。损失范围先画出来，哪些必须恢复，哪些可以放弃，优先次序一并排
2. 看仓库，代码有远程仓库，情况还好，标定表与录像悬。标定表是几周的积累，录像里存着调试过程
3. 查习惯，数据管理全凭个人自觉，谁的数据谁自己保管。硬盘在哪，谁拷过，没人说得清
4. 定规矩，所有重要数据过一遍三级清单，缺哪级补哪级。第一晚全队同时执行

**根因**：数据没有分级备份制度，重要的与不重要的一样混放，谁用谁拷。孤本一旦受损，损失不可逆，事发时甚至连丢了什么都数不清楚。标定表这类数据没有第二份来源，丢了只能从头再做一遍实验。数据散在个人手里还有第二层风险，换届离队就是一次天然清盘，没有制度兜底，知识资产跟着人走。恢复成本也常被低估，重建一份几周的标定比当初保存它贵得多。文档与实物对不上时以实物为准，定期用实物核对清单，比清单本身更要紧。

**解决**：三重备份启用，本机一份，移动硬盘一份，云端或队里服务器一份，重要文件三个地方同时有。代码走 Git 与 LFS，标定表带版本号随车，录像每天结束拷贝。执行第一晚，全队把手上所有资料过了一遍。资料清单同步进装箱单，离队交接时按清单核对。

**预防**：

- 备份动作写进日常，每天收尾十分钟，文件名带日期与场景
- 出发比赛的装箱单加一项，备份盘与资料清单随队
- 数据交接列入换届清单，人员离队前完成移交
- 每学期做一次恢复演练，从备份里恢复一份关键数据，确认备份真的打得开

延伸：三级备份的执行难点在坚持，不在技术。最实用的两个习惯是收尾十分钟的固定动作与装箱单的固定项，一个管日常，一个管出发，两处都固定下来，制度才立得住。
