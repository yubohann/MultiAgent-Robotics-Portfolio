# feishu_sync：把书稿同步到飞书知识库

本工具把 `book/` 目录下的 39 个书稿文件同步到飞书知识库的一个根节点，按篇与章组织成在线手册。

## 同步后的结构

```
根节点首页              内容 = 00_总目录.md，会覆盖根节点现有内容
├─ 卷首                 内容 = 00_卷首.md
├─ 第一篇 选型：…       其下为第 1 到 5 章
├─ 第二篇 调试：…       其下为第 6 到 10 章
├─ … 共八篇
└─ 第八篇 传承与运营    其下为第 35 到 37 章
```

- 章节顺序与篇归属全部来自 `book/00_总目录.md`，改总目录后同步会自动跟随。
- 增量同步：`state.json` 记录每个文件的内容哈希，没改动的文件直接跳过，改动过的原位重写。
- 节点被手动删除后，同步会重建，或按标题接入已存在的同名节点，避免重复。

## 一次性准备：约 5 分钟

1. 打开 https://open.feishu.cn 开发者后台，创建**企业自建应用**，名字随意，如“手册同步”。
2. 进入应用 → **权限管理**，开通：
   - `wiki:wiki`：知识库读写
   - `docx:document`：云文档读写
   - 如列表中有文档块转换 `docx:document.block:convert`，也一并开通
3. 进入应用 → **版本管理与发布**，创建版本并发布。企业内自建应用，小团队通常即时生效。
4. 把应用加入知识库：打开目标知识库 → 设置 → **成员管理** → 添加成员 → 搜索应用名 → 权限选**可编辑** → 添加。
5. 在应用“凭证与基础信息”页复制 **App ID** 与 **App Secret**。

## 配置与运行

复制 `.env.example` 为 `.env`，填入 App ID 与 App Secret，根节点已预填：

```powershell
Copy-Item .env.example .env
notepad .env
```

命令如下。本机可用 Inkscape 自带的 Python。如终端中文显示乱码，先执行 `chcp 65001`。

```powershell
& "C:\Program Files\Inkscape\bin\python.exe" feishu_sync.py check    # 联网自检
& "C:\Program Files\Inkscape\bin\python.exe" feishu_sync.py plan     # 本地预演
& "C:\Program Files\Inkscape\bin\python.exe" feishu_sync.py sync     # 执行同步
```

以后书稿改完，再跑一次 `sync` 即可，只有改动过的章节会被更新。

常用参数：

| 参数 | 作用 |
| --- | --- |
| `--only 12,15` | 只同步第 12 和第 15 章，可写章节号或文件名片段，用逗号分隔 |
| `--only root` | 只把总目录写入根节点 |
| `--force` | 忽略哈希，全部重写 |
| `--sleep 0.5` | 调用间隔调到 0.5 秒，触发频率限制时使用 |

## 公开访问：生成可免登录阅读的链接

同步完成后，在知识库：设置 → **安全** → 打开 **互联网上获得链接的人可阅读**。
整个知识库的节点都会获得免登录链接，形如：

```
https://<租户域名>/wiki/<节点token>
```

## 排错

| 现象 | 处理 |
| --- | --- |
| `App ID 或 App Secret 不正确` | 核对 .env 中的凭证是否复制完整 |
| `应用权限不足` | 开放平台确认已开通 wiki:wiki 与 docx:document，且已发布新版本 |
| `知识库节点不存在或应用无权访问` | 确认应用已加入知识库并设为可编辑，或核对根节点链接是否正确 |
| `频率受限` | 自动退避重试，仍频繁出现时把 `--sleep` 调大 |
| 页面出现重复文档 | 此前手动批量导入过的版本还在：在飞书里删除旧批次，或告诉助手处理 |

## 说明

- 根节点内容会被 `00_总目录.md` 覆盖，请在根节点上不要放置其他需要保留的内容，或改用 `--only` 避开 `root`。
- 本工具只需要 `requests` 一个第三方库。
- 凭据只保存在本机 `.env`，请勿把 `.env` 提交到 Git。
