# 流批一体湖仓 AI 课程项目

本项目合集包含现代湖仓、流处理可靠性挑战、实时推荐和短视频审核四个课程实验。

英文展示入口：[README.md](README.md)。

## 实验模块

| 模块 | 内容 | 主要技术 |
|---|---|---|
| 现代湖仓 | Kafka 采集、Flink/Dinky 处理、MinIO/Paimon 存储、Spark 分析 | Kafka、Flink、Dinky、MinIO、Paimon、Spark |
| 流处理挑战 | 数据倾斜、小文件、状态膨胀、迟到数据、Exactly-once、Schema Evolution、对象存储瓶颈 | Kafka、Flink、Paimon、MinIO |
| AI 推荐 | 实时行为特征和推荐服务 | Flink、Python 服务、模型 API |
| 短视频审核 | 本地视频审核和模型对比流程 | FastAPI、Kafka、本地 VLM 接口 |

每个模块保留自己的说明、报告、截图和代码。请进入对应目录阅读详细运行命令。
