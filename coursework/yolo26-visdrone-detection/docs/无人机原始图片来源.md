# 无人机避障可用原始图片来源

本文档用于给实验五、实验六准备原始图片。结论先写在前面：课程实验优先用 **VisDrone**，因为它是无人机视角目标检测数据集，图片和框标注都齐全；如果目标是 sim2real，请优先看 `docs/Sim2Real真实相机数据建议.md`，真实域建议使用 **ODA Dataset**、**UZH-FPV** 和自采真实相机图像。

## 1. 推荐优先级

| 优先级 | 数据源 | 适合用途 | 是否适合 YOLO26 实验 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | VisDrone DET | 无人机视角行人、车辆、非机动车检测 | 适合 | 有检测框标注，可直接转 YOLO txt；最适合实验五/六 |
| 2 | UAVDT | 无人机视角车辆检测/跟踪 | 适合，但类别较窄 | 主要是车辆，适合城市道路低空避障 |
| 3 | PULP-Dronet / ODA | 机载前视避障、碰撞概率/导航标签 | 适合论文背景，YOLO 需自标框 | 视角更接近机载前视避障 |
| 4 | Mid-Air | 合成无人机飞行图像、深度、语义 | 适合深度/避障研究，YOLO 需处理标注 | 合成环境，适合补充论文实验 |
| 5 | UZH-FPV | FPV 无人机高速飞行图像 | 适合论文背景，YOLO 需自标框 | 有运动模糊、真实飞行视角 |

## 2. 本课程建议方案

直接用 VisDrone，并把所有可碰撞目标统一标成 `obstacle`。这样训练目标清晰，报告也好解释：

```text
输入：无人机实时图像
输出：图像中的障碍物框 obstacle
用途：为无人机避障提供视觉感知结果
```

可检测对象包括：

```text
pedestrian, people, bicycle, car, van, truck, tricycle, awning-tricycle, bus, motor
```

在避障任务中，这些都可以统一视为 `obstacle`。

## 3. 自动准备 VisDrone 子集

先完成 README 中的环境安装：

```bash
conda activate yolo26
pip install -U ultralytics
```

进入实验目录：

```bash
cd ~/yubohan_[REDACTED]_exp5_6_yolo26
```

下载并准备 300 张无人机原始图像，所有类别合并为 `obstacle`：

```bash
python scripts/05_prepare_visdrone_subset.py --mode obstacle --max-images 300 --clean
```

生成结果：

```text
data_raw/images/
data_raw/labels/
configs/classes.txt
```

然后继续按 README 执行：

```bash
python scripts/01_split_yolo_dataset.py
python scripts/02_make_data_yaml.py
python scripts/03_train_yolo26.py --device 0
```

如果没有 GPU：

```bash
python scripts/03_train_yolo26.py --device cpu
```

## 4. 如果想保留 VisDrone 10 类

执行：

```bash
python scripts/05_prepare_visdrone_subset.py --mode visdrone10 --max-images 500 --clean
```

类别会写入：

```text
configs/classes.txt
```

内容为：

```text
pedestrian
people
bicycle
car
van
truck
tricycle
awning-tricycle
bus
motor
```

论文避障场景建议先用 `obstacle` 单类；如果你要展示更强的检测效果，再用 `visdrone10`。
