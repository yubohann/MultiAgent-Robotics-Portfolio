## 关键路径

关键路径为：

`1.1 团队角色与计划确认 -> 1.2 初步调查 -> 2.1 功能模块拆分 -> 3.2 UML 用例图 -> 4.1 ER 与 ORM 建模 -> 7.1 系统代码补齐 -> 6.2 自动化测试编写 -> 7.2 代码审查与截图留存 -> 7.3 最终报告归档`

总工期约 21 个工作日。关键路径上的主要风险是需求图与代码实现不一致、测试滞后、截图缺失。

## 技术方案补充

| 方案 | 内容 |
| --- | --- |
| 硬件架构 | 普通 PC 或笔记本运行 Flask 服务和 SQLite 数据库，浏览器作为客户端。 |
| 网络架构 | 开发环境为本机浏览器访问 `127.0.0.1:5000`；生产设想为门店局域网终端访问 Web 服务。 |
| 软件架构 | Flask 应用工厂、SQLAlchemy ORM、Jinja2 模板、静态 JavaScript、SQLite。 |
| 实施方案 | 使用 `uv sync` 安装依赖，`uv run python run.py` 启动，最终报告、图表、代码和测试统一提交 Gitee。 |
