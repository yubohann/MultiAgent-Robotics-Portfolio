# 超市管理系统

这是一个基于 Flask、SQLAlchemy 和 SQLite 的课程设计项目，覆盖商品、库存、结算、销售、财务、公告、经营分析、智能助手，以及会员、员工、供应商和系统参数等模块。

英文展示入口：[README.md](README.md)。应用代码在 `app/`，测试在 `tests/`，课程报告和答辩材料在 `reports/`，系统分析图和可编辑 draw.io 源文件分别在 `supermarket-management-diagrams/` 与 `supermarket-management-diagrams-drawio-editable/`。

快速启动：

```powershell
uv sync
uv run python run.py
uv run pytest
```

项目属于课程工程作品，数据库、演示账号和运行数据只用于本地开发验证。
