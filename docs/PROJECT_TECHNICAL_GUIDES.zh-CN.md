# 项目技术导览索引

每个项目现在配有两份独立中文文档：

- `project-summaries/`：约 300 字的快速概括，用于作品集浏览和申请材料定位。
- `project-deep-dives/`：技术深度导览，介绍架构、源码模块、调用链、开发过程、知识点、运行入口、测试和证据边界。

深度导览以当前本地 checkout 的 README、入口、配置、测试和证据文件为依据，明确区分源码/框架、CPU/静态检查、仿真/回放、Isaac/PhysX 原生证据、真实硬件证据和正式 benchmark 资格。它们不能替代项目自己的 README、私有数据协议、实验 manifest 或第三方许可证。

## 阅读约定

选项目时先读 300 字概括，再结合深度文档阅读项目自己的 README、源码、测试、配置和证据。文档中的命令是入口，不表示已经在所有机器上运行；只有能关联到 run、seed、数据/场景版本、配置、硬件/运行时和产物路径的内容，才应作为结果引用。
