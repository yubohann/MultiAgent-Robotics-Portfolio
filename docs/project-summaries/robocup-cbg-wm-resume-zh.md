# 面向规则约束多机器人战术的不确定性感知反事实信念图世界模型

**项目负责人及核心开发者** | **2025年3月 - 2025年10月**  
**核心技术栈：** ROS 2 Jazzy，Isaac Lab，Python，PyTorch，MARL，SAC Flow，世界模型强化学习，CVaR MPC。  
**感知与部署：** Nav2，robot_localization，AprilTag，RGB-D，LiDAR，IMU。  
**项目概述：** 面向部分可观测双机器人视觉对抗任务，研究目标遮挡，观测延迟和可推动障碍存在时的规则约束决策，构建从局部感知到风险控制动作选择的对象中心世界模型链路。

- 将多源传感器观测编码为包含位姿与速度，可见性与观测年龄，协方差等信息的对象中心信念图，使用 23 个固定类型 token 表达双机器人，目标，可推动障碍和受保护区域阻挡物，并在遮挡时累积不确定性。
- 构建类型化对象交互动力学与概率集成世界模型，预测状态变化，奖励，终止状态以及碰撞，阻塞，非法任务触发和视线违规等规则风险。
- 设计成对反事实干预，对比障碍箱体或受保护区域阻挡物保留与移除时的状态，奖励，风险和图关系变化，用于评估模型对关键战术因素的敏感性。
- 将 Flow 候选轨迹接入 CVaR 风险模型预测控制，结合收益下尾风险，规则风险上尾和模型分歧选择短时域动作，再由规则感知动作屏蔽层检查目标归属，视线，射程，停留时间和碰撞约束。
- 采用集中训练和分散执行的多智能体深度强化学习框架，围绕目标选择，受保护区域接近，阻挡，恢复，任务触发门控和风险偏好学习六类高层战术控制，并以残差专家策略保留规则先验。
- 集成 ROS 2 与 Isaac Lab，结合 AprilTag，Nav2 和状态估计接口，完成双机器人 1v1 场景的实机实验。另构建独立的规则级仿真基准，按 5v5 至 50v50 课程完成 256 局评估。
