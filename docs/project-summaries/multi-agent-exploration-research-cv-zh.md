# 多机器人协作探索与导航研究

研究负责人、独立开发者　　　　　　　　　　　　　　　　　2025年10月至今

研究主题：面向部分可观测三维环境，利用局部感知、空间连通关系和执行反馈，研究多机器人协同探索与目标搜索。

感知与建模：部分可观测马尔可夫决策过程（POMDP）；不确定地图先验与局部几何信念；RGB-D 语义建图；YOLO-World 开放词汇检测与 Mobile-SAM 像素级分割；深度反投影与局部点云；LiDAR 与惯性测量单元（IMU）时空对齐；程序化三维场景生成。

规划与控制：前沿探索；自由空间与未知空间连通图及可达性分析；容量约束车辆路径问题（ACVRP）与 LKH 求解；视觉语言模型（VLM）全局区域分配；A*、动力学 A*、快速行进法（FMM）；B 样条轨迹；虚拟结构编队；通信连通性约束、碰撞检查、安全动作过滤。

学习与优化：多智能体深度强化学习（MARL）；Graph-SAC 与 Graph-MASAC；受约束软演员评论家（Constrained SAC）；后继特征表示；行为克隆与数据聚合（DAgger）；质量多样性优化与 MAP-Elites 型档案；执行反馈驱动的候选动作选择与策略档案。

## 独立研究模块

### 1. 图结构多机器人规划与安全控制——AeroGate Graph

• 将机器人、路线节点和障碍物编码为带邻接矩阵和节点掩码的图观测。接入 Isaac Lab 与 PhysX 仿真适配层，结合 A* 全局路径、虚拟结构编队控制、Graph-SAC 与 Graph-MASAC，支持可变规模团队的协作决策。

• 施加速度与加速度约束、线段级碰撞检查、动态闸门及障碍物状态处理和安全动作过滤。策略输出在执行前接受运动学与编队约束检查；记录路径长度、障碍物净空、编队误差和规划延迟，用于单机器人与多机器人场景的受控比较。

### 2. 程序化三维搜索基准与多传感器物理仿真环境——AeroCityBench 与 Rivermark

• 面向多机器人三维搜索中的场景和评测标准不统一问题，设计程序化城市布局与统一任务接口，规范三维位姿、传感器观测、动作片段、通信消息和搜索事件；分离策略可见观测与仅供评测的信息，为经典规划、多智能体强化学习和视觉语言策略提供统一的输入输出边界，并分别评估几何搜索和语义目标搜索。

• 在 Isaac Sim 与 PhysX 中建立多机器人三维搜索场景，对齐彩色图像、深度、语义标签、LiDAR、惯性测量和机体状态的时间戳、坐标系与传感器外参，形成统一的多传感器观测接口。

• 将局部占据与自由空间估计、前沿候选、区域分配、通信连通性检查和碰撞检查纳入在线执行循环，为经典规划、多智能体强化学习、质量多样性方法和视觉语言策略提供统一的集成与比较接口。

### 3. 执行反馈驱动的质量多样性协作探索——HM3D 衍生三维场景与 Realised-QD

• 根据实际执行回执更新质量多样性策略档案；从实际轨迹、覆盖范围、重复搜索、空间角色分配、通信状态和安全干预中提取行为描述，用于刻画协作行为。

• 构建基于后继特征和约束成本的候选动作评价方法，将探索收益、执行时长和安全成本纳入协作决策，并保留行为差异明显且具备执行可行性的策略。

### 4. 室内语义目标搜索与连通性感知的几何探索——HM3D、Co-NavGPT2 与 C2

• 在 Co-NavGPT2 语义搜索主线上，于 HM3D 室内三维基准中实现并扩展双机器人 RGB-D 导航流程。通过开放词汇检测和像素级分割提取目标线索，将深度观测反投影为局部点云，维护共享俯视地图，并从已知自由空间与未探索空间的边界提取前沿。

• 在 C2 几何执行主线上维护自由空间、未知空间和连通关系，结合任务分配、A*、动力学路径规划、B 样条轨迹平滑和局部碰撞检查进行在线重规划，分析地图变化、通信状态和执行误差对团队探索的影响。

• 设计 RegionEvidence 区域证据接口，作为连接 HM3D RGB-D 语义线索与 C2 几何前沿的中间表示，统一承载可达候选、局部位姿、时间新鲜度、负证据和执行反馈。策略依据在线区域证据完成区域排序、任务分配和局部执行；语义搜索与几何探索分别采用对应指标进行评估。
