# ROBOCON 机器人篮球实机自主系统：LiDAR-IMU 定位与投篮执行

**激光雷达与感知方向负责人** | **2024年6月 - 2025年10月**  
**技术栈：** ROS 2，C++，Python，FAST-LIO2，Livox MID-360（内置 IMU），TF2，Nav2，Gazebo，YOLOv5，RGB-D，UART，ESP-NOW，STM32，CAN，Linux。

- 针对竞赛实机急加速、底盘振动和机构扰动造成的点云畸变与定位波动，集成 Livox MID-360 内置 IMU 与 FAST-LIO2 链路，完成传感器安装、外参与时间同步配置，建立场地建图和固定地图定位流程，并将定位输出接入导航与投篮执行。
- 构建位姿到投篮参数的接口，根据机器人位姿与篮筐坐标计算距离和航向误差，结合含重力，空气阻力和马格努斯力的数值模型进行离线参数标定，通过 UART 将距离相关指令下发至 STM32 控制层。
- 将既有 YOLOv5 与 RGB-D 观测接入 ROS 2，依据置信度，深度，稳定性和观测新鲜度控制投篮动作。对接 ESP-NOW 位置同步和串口控制边界，将接球，传球和投篮流程接入任务状态与急停逻辑。
- 在 Gazebo 中构建 MID-360 传感器与比赛场地仿真，模拟逐点扫描时序和 IMU 输入，复用 ROS 2 定位、感知与控制接口，再将同一套接口迁移到真实竞赛机器人进行现场联调。
- 负责定位，感知，导航，双车通信和嵌入式控制联调，团队获得第24届中国大学生机器人大赛 ROBOCON 机器人篮球项目全国二等奖以及机器人篮球投篮专项赛全国二等奖。
