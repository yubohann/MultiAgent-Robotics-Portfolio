# Stream-Batch Lakehouse AI Portfolio：300 字概括

该合集包含现代湖仓、七类流处理可靠性挑战、实时推荐和短视频流审核四个课程实验。现代湖仓用 Kafka、Flink/Dinky、MinIO、Paimon 和 Spark 完成订单流采集、ODS/DWS 存储与流批核验；挑战实验围绕数据倾斜、小文件、状态膨胀、乱序、exactly-once、schema evolution 和对象存储瓶颈组织独立验收；推荐实验用 Flink 行为特征、Kafka 和 Python/DeepFM 服务生成实时推荐；短视频实验以 FastAPI、SQLite、FFmpeg、Kafka 和 Ollama VLM 处理真实视频并保留多模型 baseline。项目展示从数据流、状态、湖仓到 AI 服务的端到端工程思维，但四个模块运行环境和证据独立，课程截图、日志和本地模型不能包装成统一生产平台或公开性能承诺。
