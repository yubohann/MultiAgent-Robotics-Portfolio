# YOLO26 + VisDrone Detection：300 字概括

该课程项目实现 VisDrone 航拍目标检测的完整实验链路：环境 smoke、子集准备、YOLO 目录整理、train/val 划分、`data.yaml` 生成、YOLO26n 训练、验证、预测和 ONNX 导出，并提供从真实无人机视频抽帧的脚本。代码入口集中在 `scripts/00..06`，配置、示例图、截图、实验报告和 sim-to-real 说明分目录保存。项目强调数据格式、模型权重、推理输出和边缘部署格式之间的连接，适合展示计算机视觉入门和工程脚本能力。真实视频抽帧不等于视频级检测评估，课程截图不等于真实无人机部署性能；mAP、延迟、权重和 ONNX 结果必须绑定数据子集、seed、硬件和运行时版本，不能由一次训练推导公开 SOTA。
