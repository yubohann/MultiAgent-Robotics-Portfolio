# Supermarket Management System：300 字概括

Supermarket Management System 是基于 Flask、Flask-SQLAlchemy、SQLite、Jinja2 和原生 JavaScript 的课程级门店管理系统。app factory 负责数据库、日志、默认用户/分类、第二阶段演示数据和 SQL seed；路由与模型覆盖认证、商品、库存流水、收银、销售订单、财务日结、公告、经营分析、智能助手，以及会员、员工、供应商和系统参数。页面、API、测试、ER/DFD/UML 图、答辩 PPT 和报告均保留在仓库中。pytest 覆盖认证、权限、商品、库存、结算、财务、公告和错误路径，coverage gate 是工程验收目标。项目适合展示业务建模、Web 分层、事务和测试意识，但默认账号、SQLite 单机数据库和演示数据只用于课程开发，不能直接等同于生产零售系统或真实支付/并发能力。
