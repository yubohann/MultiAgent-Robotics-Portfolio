# Machine Learning Coursework：300 字概括

Machine Learning Coursework 合并两类课程成果：十个从零实现的经典算法，以及 PCA/LDA、Iris kNN 和 Wine kNN-versus-ID3 综合作业。经典算法覆盖 AdaBoost、Apriori、C4.5、CART、EM、K-means、KNN、Naive Bayes、PageRank 和 SVM，分别保留数据、源码、README、参数和结果；Assignment 3 进一步加入降维、分类比较和可视化。项目强调从公式、伪代码到 Python/NumPy 实现，再用图表解释模型行为，适合展示机器学习基础、数据处理和实验表达能力。它属于课程工程，不是统一的生产 ML 库或论文基准；典型输出依赖本地数据、随机种子和脚本参数，不能把单次准确率或课程报告包装成 SOTA 结论。
