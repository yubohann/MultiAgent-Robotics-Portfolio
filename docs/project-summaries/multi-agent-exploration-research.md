# 多机器人协作探索与导航研究

**研究负责人、核心开发者　　　　　　　　　　　　　　　　　2025年10月至今**  
**研究主题：** 面向部分可观测三维环境，研究多机器人如何依据局部感知、空间连接关系和执行反馈进行协同探索与目标搜索。  
**技术栈：** Python；C++；NumPy；PyTorch；Gymnasium；PettingZoo；Habitat-Sim；Habitat-Lab；Isaac Sim；Isaac Lab；PhysX；机器人操作系统（ROS 2）。  
**运行环境：** Linux 与 WSL。  
**感知与建模：** POMDP；不确定地图先验与局部几何信念；RGB-D 语义建图；YOLO-World 开放词汇检测 + Mobile-SAM 像素级分割；深度反投影与局部点云；LiDAR-IMU 时空对齐；程序化三维场景生成。  
**规划与控制：** 前沿探索；自由与未知空间连通图及可达性分析；ACVRP 与 LKH；VLM 全局区域分配；A*、动力学 A*、FMM；B 样条轨迹；虚拟结构编队；通信连通约束、碰撞检查、安全动作过滤。  
**学习与优化：** MARL；Graph-SAC 与 Graph-MASAC；Constrained SAC；Successor Features；行为克隆与 DAgger；QD 与 MAP-Elites；执行反馈候选动作选择与策略档案。

**五个独立研究模块**

**1. 图结构多机器人规划与安全控制（AeroGate Graph）**  
• 将多机器人路径规划中的机器人、路线节点和障碍物编码为带邻接矩阵与节点掩码的图观测，接入 Isaac Lab 与 PhysX 仿真适配层，结合 A* 全局路径、虚拟结构编队和图结构软演员评论家（Graph-SAC 与 Graph-MASAC），构建可变规模团队的协作决策环境。  
• 实现速度与加速度约束、线段级碰撞检查、动态闸门与障碍状态变化处理和安全动作过滤器，使策略输出经过运动学与队形约束后再执行；统一记录路径长度、障碍净空、队形误差和规划延迟，用于比较单机器人、静态多机器人和动态场景。  

**2. 程序化三维搜索基准与多传感器物理仿真环境（AeroCityBench 与 Rivermark）**  
• 面向多机器人三维搜索中的场景和评测标准不统一问题，设计程序化城市布局与统一任务接口，规范三维位姿、传感器观测、动作片段、通信消息和搜索事件；分离策略可见观测与评测信息，为经典规划、多智能体强化学习和视觉语言策略提供同一输入输出边界，并按任务类型分别统计几何搜索与语义目标搜索指标。  
• 在 Isaac Sim 与 PhysX 中建立多机器人三维搜索场景，处理彩色图像、深度、语义、激光、惯性和机体状态在时间戳、坐标系与外参上的对齐，形成统一的多传感器观测接口。  
• 将局部占据与自由空间估计、前沿候选、区域分工、通信连接和碰撞检查接入在线执行循环，为经典规划、多智能体强化学习、质量多样性和视觉语言策略提供统一接入与比较接口。  

**3. 执行回执驱动的质量多样性协作探索（HM3D 衍生三维场景与 Realised-QD）**  
• 以实际执行回执更新质量多样性策略档案，从执行轨迹计算覆盖范围、重复搜索、空间分工、通信状态和安全干预等行为描述，形成可比较的协作行为表征。  
• 构建基于后继特征与约束成本的候选动作评价方法，将探索收益、持续时间和安全成本纳入协作决策，并保留行为差异和执行可行性的策略。  

**4. 室内语义目标搜索与连通性约束的几何探索（HM3D 室内三维场景基准与 Co-NavGPT2、C2）**  
• 重建并扩展 Co-NavGPT2 的语义搜索主线，在 HM3D 室内三维场景中实现双机器人 RGB-D 导航链路：利用开放词汇检测与像素级分割提取目标线索，将深度观测反投影为局部点云，维护共享俯视地图，并从已知自由空间与未知空间边界生成前沿。  
• 重建并扩展 C2 的几何执行主线，维护自由空间、未知空间和连通关系，结合任务分配、A* 与动力学路径规划、B 样条轨迹平滑和局部碰撞检查进行在线重规划，分析地图变化、通信状态和执行误差对团队探索的影响。  
• 自主设计区域证据（RegionEvidence）接口，将 HM3D 的 RGB-D 语义提示与 C2 的几何前沿统一为包含可达候选、局部位姿、时间新鲜度、负证据和执行反馈的中间表示；策略输入由在线观测形成的区域证据构成，并据此完成区域排序、任务分配和局部执行，分别采用语义目标搜索与几何探索指标进行评估。  

**实验设计：** 采用成对对照，固定场景划分、观测权限、控制器、动作预算和随机种子，仅改变前沿分配、图结构策略或质量多样性组件；分别以语义目标搜索成功率与路径效率、几何空间覆盖与执行安全性评价。
