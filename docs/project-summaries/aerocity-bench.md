# AeroCityBench：300 字概括

AeroCityBench 是面向程序化城市和四架 CF2X 的多 UAV 搜索/巡检 benchmark 工程。项目定义 CitySpec、公开 observation/action ABI、L0 控制器、L1 外部进程适配、Isaac capture、release gate、资产审计和 readiness status；公共 atlas 与 evaluator-private target、support site、witness、seed 分离，所有运行由 manifest、源代码 revision、Python 环境和 receipt 哈希绑定。L0 只负责校准和回放，native capability probe、visual review、CF2X preflight 与 formal score eligibility 也分开记录。项目展示的是 benchmark 合同、信息泄漏防护、物理执行证据和科学治理能力，而非单纯的城市渲染。公开源码不包含私有城市、目标和 NVIDIA 资产；任何正式结果都必须绑定当前 release、完整 native episode 和 eligibility 状态。
