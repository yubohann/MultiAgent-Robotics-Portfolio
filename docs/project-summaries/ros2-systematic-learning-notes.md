# ROS 2 Learning Notes：300 字概括

ROS 2 Learning Notes 是一套面向机器人系统工程的持续型技术手册，覆盖节点、topic、service、action、参数、launch、TF2、QoS、rosbag、Nav2、MoveIt2、DDS、嵌入式部署、安全容错和云机器人。内容按“概念、最小命令、故障模式、工程取舍”组织，重点解释时间戳、坐标树、QoS 兼容、生命周期、调试和系统启动恢复，而非简单罗列 API。`README.md`、`README.zh-CN.md` 和 `完整目录.md` 构成阅读入口。它适合证明持续学习、系统化整理和机器人软件基础，可作为 MID-360、RoboCup 等项目的背景材料；具体版本、命令、硬件性能和部署结论仍需在目标 ROS 2 环境中复核，笔记本身不是可安装产品或硬件 benchmark。
