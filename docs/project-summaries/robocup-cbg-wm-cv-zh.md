# 面向规则约束多机器人战术的不确定性感知反事实信念图世界模型

**项目负责人及核心开发者** | **2025年3月 - 2025年10月**  
**研究概述：** 面向部分可观测双机器人视觉对抗任务，研究目标遮挡，观测延迟以及可推动障碍改变路线和视线时的规则约束决策。系统利用对象中心信念图和短时域世界模型，在局部观测下评估行动收益与规则风险。  
**技术栈：** ROS 2 Jazzy，Isaac Lab，Python，PyTorch，NumPy，Gymnasium，Stable-Baselines3，多智能体深度强化学习，SAC Flow，基于世界模型的强化学习，CVaR 模型预测控制，Nav2，slam_toolbox，robot_localization，OpenCV，AprilTag，RGB-D，LiDAR，IMU，差速驱动仿真，Sim2Real 接口。  
**研究方法：** 不确定性信念状态，类型化对象交互图，概率集成世界模型，反事实成对干预，Flow 提议轨迹，CVaR 风险模型预测控制，规则感知动作屏蔽，集中训练与分散执行，残差专家策略。

- 设计 ROS 2 与 Isaac Lab 组成的双机器人视觉对抗环境，将目标归属，合法接近范围，视线和持续观测时间作为任务触发规则，同时建模可推动障碍，受保护区域阻挡物以及碰撞穿透约束。
- 将 RGB-D，LiDAR，IMU，轮速，ToF 及接触状态转化为固定类型的对象中心 belief tokens。每个 token 编码位姿与速度，尺寸与可见性，观测年龄与协方差，遮挡状态与存在状态，形成 23 个 token 共 368 维的信念状态。目标被遮挡时保留上次信念并累积不确定性。
- 构建包含观测关系，接触关系，路线阻塞关系，区域保护关系，威胁关系，邻近关系和视线关系的类型化交互图。将对象自身动力学与对象交互动力学分开建模，并保持对象及其类型联合置换下的图结构等变性。
- 实现由 5 个成员组成的概率世界模型，预测对象状态变化及其高斯分布，奖励分布，终止状态，可见性和存在状态，并同时输出机器人或目标碰撞，运动阻塞或穿透，非法任务触发以及视线或距离违规四类规则风险。
- 设计成对反事实干预，将可推动箱体保留与移出导航或目标交互路径进行对照，将受保护区域阻挡物保留与提前移除进行对照。模型学习状态，奖励，风险和交互边的变化，并与配对仿真干预比较变化方向，用于评估反事实敏感性和方向一致性。
- 将 Flow actor 生成的候选动作序列接入风险 MPC，在短时域内依据低尾部 CVaR 收益，规则风险上尾 CVaR 和集成模型分歧进行排序，每个决策周期只执行选中序列的第一步，再交由动作屏蔽层完成规则与安全过滤。
- 定义六类高层战术控制：目标选择，受保护区域接近时机，阻挡或干扰，恢复请求，任务触发门控和风险偏好。采用残差专家策略调整规则感知先验，并以集中训练和分散执行方式支持双机器人协同决策。
- 将 AprilTag 目标感知，robot_localization 状态估计，Nav2 导航和任务执行控制纳入 ROS 2 部署契约，保持仿真策略与机器人运行时之间的接口边界，并完成双机器人 1v1 场景的实机实验。
- 构建独立的规则级仿真基准，按 5v5 至 50v50 的分阶段课程完成 256 局评估和 Isaac Lab 战术可视化，用于研究规模扩展下的区域控制，防护条件和合法任务执行闭环。
