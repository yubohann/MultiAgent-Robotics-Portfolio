# ROBOCON 机器人篮球的 LiDAR-IMU 定位与投篮参数集成

**激光雷达与感知负责人** | **2024年6月 - 2025年10月**  
**技术栈：** ROS 2 Humble，C++17，Python，Linux，FAST-LIO2，Livox MID-360（内置 IMU），PCL，Eigen，TF2，Nav2，Gazebo，YOLO，RGB-D，UART，ESP-NOW，STM32，CAN。

- 在受急加速、底盘振动、机构扰动和场地局部遮挡影响的竞赛实机上集成 Livox MID-360 内置 IMU 与 FAST-LIO2 激光雷达惯性定位。完成传感器安装、外参与时间同步标定，建立场地建图和固定地图定位流程，服务于导航和投篮执行。
- 通过 ROS 2 位姿接口统一激光雷达里程计，固定地图定位和导航模块，加入位姿新鲜度，地图状态和异常跳变检查，为目标对准和底盘控制提供一致的定位状态。
- 构建基于位姿的投篮接口，根据机器人位姿与篮筐坐标计算距离和航向误差，将距离映射为发射速度参数，并通过 UART 向 STM32 投篮和底盘控制硬件发送指令。
- 建立离线篮球弹道模型，纳入重力，空气阻力和马格努斯力。使用模拟退火搜索不同投篮距离下的初始发射速度，将物理模型结果作为在线距离到速度映射的标定参考。
- 将 YOLO 和 RGB-D 目标检测接入 ROS 2，规范化置信度，深度，稳定性和时间戳字段，根据目标有效性和观测新鲜度开放投篮动作。接入 ESP-NOW 位置同步，围绕双车任务流程处理消息确认，心跳，超时恢复和急停。
- 在 Gazebo 中构建 MID-360 仿真，复现 Livox 扫描时序和 IMU 输入，沿用 ROS 2 接口完成向实机迁移前的流程联调。
- 负责现场集成，覆盖激光雷达定位，感知，导航，通信，UART 和 STM32 控制，支撑团队在第24届中国大学生机器人大赛（ROBOCON）机器人篮球和机器人篮球投篮项目中获得全国二等奖。
