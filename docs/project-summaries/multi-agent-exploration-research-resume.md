# 多机器人协作探索与导航研究

**研究负责人兼核心开发者　　　　　　　　　　　　　　　　2025年10月至今**  
面向部分可观测三维环境，研究多机器人如何结合局部感知，利用空间连通关系，并根据执行反馈完成协同探索与目标搜索。  
**技术栈：** Python；C++；NumPy；PyTorch；Habitat-Sim；Habitat-Lab；Isaac Sim；Isaac Lab；PhysX；机器人操作系统（ROS 2）。  
**研究方法：** 以 RGB-D 语义建图和开放词汇视觉感知构建环境表示，使用前沿探索与连通图规划完成区域选择，结合 ACVRP 和 LKH 处理任务分配，再通过 A* 与动力学路径规划生成可执行路线。在决策层采用多智能体强化学习，使用 Graph-SAC 与 Graph-MASAC，并引入受约束软演员评论家和后继特征。训练与策略筛选阶段结合行为克隆和 DAgger，同时采用质量多样性优化。

• **图结构多机器人规划与安全控制（AeroGate Graph）：** 面向可变规模团队协作，将机器人状态与路线节点及障碍物统一编码为图观测。把 A* 全局规划和虚拟结构编队接入 Graph-SAC 与 Graph-MASAC，并在执行端同时进行运动学约束检查，碰撞检查和安全动作过滤。

• **程序化三维搜索基准与多传感器物理仿真环境（AeroCityBench 与 Rivermark）：** 针对三维搜索中场景与评测标准不一致的问题，建立统一任务协议，分别定义场景与位姿，规定传感器观测和动作执行方式，明确通信消息及目标确认规则。策略可见观测与评测信息分开处理。在 Isaac Sim 与 PhysX 中完成多传感器状态对齐，在线搜索流程负责占据估计和前沿生成，执行区域分工并检查通信连通性与碰撞风险，支持几何搜索与语义搜索的统一比较。

• **执行反馈驱动的质量多样性协作探索（HM3D 衍生三维场景与 Realised-QD）：** 根据执行回执，从实际轨迹中提取覆盖范围和重复搜索等空间行为，并记录团队分工，通信状态及安全干预，构造质量多样性策略档案。候选动作评价结合后继特征与约束成本，使策略同时考虑探索收益，执行时长和安全成本，并保留具有行为差异且可以执行的策略。

• **室内语义搜索与几何协同执行（HM3D 与 Co-NavGPT2 及 C2）：** 围绕 HM3D 与 Co-NavGPT2 的语义搜索以及 C2 的几何执行，构建从 RGB-D 导航到自由空间建模，再到任务分配和在线重规划的流程。设计区域证据接口（RegionEvidence），把在线获得的语义提示和几何前沿与可达性及执行反馈共同组织为区域级表示，用于区域排序和任务分配，并驱动局部执行。
