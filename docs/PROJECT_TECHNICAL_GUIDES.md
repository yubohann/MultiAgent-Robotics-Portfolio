# Project Technical Guides

This directory contains a compact summary and one or more reader-facing technical guides for each project:

- `project-summaries/`: a compact Chinese overview of about 300 Chinese characters for portfolio browsing.
- `project-deep-dives/`: technical guides covering architecture, source modules, development path, knowledge map, execution chain, tests, evidence organization, and application-facing interpretation. Some projects also include an extended competition or English guide.

The deep guides are written from the current local checkout. They distinguish source/framework evidence, CPU/static checks, simulation or replay evidence, native Isaac/PhysX evidence, hardware evidence, and formal benchmark eligibility. They do not replace project READMEs, experiment manifests, private data agreements, or third-party licenses.

## Reading convention

Read the summary first when selecting a project, then use the deep guide together with that project's README, source code, tests, configuration, and evidence files. A command shown in a guide is an entry point, not proof that it has been executed on every machine. A result is only a result when its run, seed, data or scene revision, configuration, hardware/runtime, and artifact path are available.
