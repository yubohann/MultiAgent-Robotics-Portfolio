# 执行计划：打断短视循环，完成论文主实验（2026-08-08 冻结版）

## 0. 问题定义（已用 A/B 数据确认）

- 症状：40s 四机里程 15-29m（目标 ≥70m）、决策数 4-8（目标 15-25）、
  00626 覆盖 12-14%（目标 ≥30%）、00459 52%（目标 ≥70%）。
- 已排除：standoff（1.5-2.5 vs 4-6m 无差异）、滚动窗口（有害）、
  传感方向数（6 vs 26 无差异）。
- **根因（两层）**：
  1. 候选池构建昂贵（20-180s 墙钟/决策）→ 40s 只能 4-8 次决策；
  2. 增益视野循环：稀疏观测只"看见"近处簇 → 高增益簇全在近处 →
     选择器永远选短观察位点 → 飞得少 → 看得更近。
- 安全事实：长路线全程经 PhysX 守卫逐段验证（0.9m 包络/0.5m 终端），
  不撞墙；长路线少的代价是守卫净空严，不是安全缺口。

## 2. 阶段划分与 Gate

### 阶段 0：基线冻结（已完成）
回退 standoff/rolling（A/B 结论入代码注释）；26 方向对齐合同；
63 个过时配置归档；崩溃根因（C 盘空间）修复。**Gate：全部单测绿。**

### 阶段 1：候选池增量缓存（让规划便宜，前提）
- 1a. 跨决策复用 belief 未变时的 frontier 簇/观察位点/route_progress 前缀；
- 1b. 路线守卫缓存跨决策（guard segment_cache 按 (agent, start, end) 保留，
  仅在 belief 增量影响时失效）；
- 1c. 观察位点/前沿簇按"新观测体素邻域"增量更新，不做全量重扫。
- **验收**：00626 decision_wall 均值 ≤30s（当前 20-180s），40s 决策数 ≥12。
- **风险**：belief 变化判定（content_sha256 已存在，可作缓存键）。

### 阶段 2：打断增益视野循环（核心机制）
- 2a. 增益定义加"未观测区域潜在价值"项：目标区域未知体素密度 × 距离衰减
  （信息论探索），region_access/route_progress 不再只按已观测簇打折；
- 2b. 选择器执行里程偏好（VORL-EXPLORE 式）：score += w_len × 可完成路线长度
  （w_len 冻结，路线仍由守卫/预算决定，不设最小长度）；
- 2c. region_access 低频承诺：跨决策保留的全局访问路线（任务保留升级为
  "全局路线 + 局部微调"两层，RACER/FUEL/FAEP 模式）。
- **验收**：00626 每决策平均团队路线 ≥8m，00459 ≥6m；决策数不下降。
- **风险**：w_len 过大导致无视增益 → 配 2a 一起调；2c 与 1b 缓存耦合。
